# 🗳️ Bihar Assembly Election Data Analysis & Power BI Dashboard

# 📌 Project Overview

This project analyzes the **Bihar Assembly Election Dataset (2000–2025)** using **Python** for data cleaning and exploratory data analysis (EDA), and **Power BI** for building an interactive dashboard.

The goal of this project is to uncover meaningful insights about election trends, voter turnout, political party performance, and constituency-wise statistics through visualizations and interactive reports.

---

# 🎯 Project Objectives

- Perform Data Cleaning and Preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Analyze voter turnout across constituencies
- Compare political party performance
- Identify winning margins and election trends
- Build an interactive Power BI Dashboard
- Generate meaningful insights from election data

---

# 📂 Dataset Information

The dataset contains Bihar Assembly Election data from **2000 onwards**, including the latest election information.

### Dataset includes:

- Assembly Constituency (AC)
- AC Number
- District
- Category (GEN / SC / ST)
- Winning Candidate
- Political Party
- Total Electors
- Total Votes Polled
- Poll Percentage
- Winning Margin
- Margin Percentage
